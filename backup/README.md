# Backup recordings

Videos are **not** committed (see `.gitignore`). Keep copies on the presenting laptop and on a USB stick.

## Naming

```
demo-a_take1_2026-11-22.mp4
demo-b_take1_2026-11-22.mp4
demo-a_FINAL_2026-11-24.mp4
demo-b_FINAL_2026-11-24.mp4
```

## Rules

- Record the **rehearsals themselves**; do not run extra sessions only for recording (saves usage limit).
- One clip per demo, so only the failing part has to be replaced during the talk.
- Record without narration; narrate live over the clip.
- Before sharing anywhere: hide e-mail addresses, account names, keys and tokens (crop `/status` output).
- Also keep 3–5 screenshots per demo as a second fallback.
- During the talk, say plainly that the clip is a recording.
